# NotepadOnline

Um bloco de notas online simples e intuitivo para criar, editar e organizar anotações diretamente pelo navegador.

## Demonstração

![Demonstração](image.png)

## Tecnologias

O projeto foi desenvolvido utilizando:

- [React](https://react.dev/) — construção da interface
- [Express](https://expressjs.com/) — desenvolvimento do servidor e API

## Funcionalidades

- Criar anotações
- Editar anotações
- Visualizar anotações
- Interface simples e responsiva
- Comunicação entre frontend e backend

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/ryancunhha/NotepadOnline.git
```

### 2. Acesse o diretório

```bash
cd NotepadOnline
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

Após instalar as dependências, execute o comando correspondente à configuração do projeto:

```bash
npm run dev
```
